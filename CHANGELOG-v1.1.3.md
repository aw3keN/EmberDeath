# EmberDeath v1.1.3

## Changes

- Added separate server-version adapter sources for `1.16.5`, `1.17`, `1.18`, `1.19`, `1.20`, `1.21`, `26.1`, and `26.2`.
- Changed the compile target to Paper API `1.16.5` and Java `8` for broad runtime compatibility.
- Added runtime adapter selection based on the detected server version.
- Used Spigot API `1.16.5` as the shared Java 8-compatible compile baseline.
